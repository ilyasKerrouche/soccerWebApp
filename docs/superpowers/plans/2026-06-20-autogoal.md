# Autogoal (Own Goals) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permettere all'admin di registrare autogoal per partita; gli autogoal contano nel punteggio avversario ma non nelle statistiche personali del giocatore.

**Architecture:** Aggiunta della colonna `own_goals` su `match_players`. Il form admin mostra un toggle "OG" per ogni riga marcatore. La query del profilo giocatore espone gli autogoal per mostrarli nella cronologia partite.

**Tech Stack:** Next.js 14 App Router, Supabase (Postgres), React, TypeScript, Tailwind CSS

## Global Constraints

- Nessuna nuova dipendenza npm
- La colonna `goals` rimane invariata — solo `own_goals` è nuova
- Gli autogoal non entrano in `total_goals`, `scoring_streak`, né media gol
- Nessuna modifica alle statistiche portiere

const handleSubmit = async (e: React.FormEvent) => {

  setLoading(true)

    const ownGoalsMap = new Map<string, number>()

    scorersA.forEach((s) => {

        ownGoalsMap.set(s.player_id, (ownGoalsMap.get(s.player_id) ?? 0) + s.goals)

      } else {
        goalsMap.set(s.player_id, (goalsMap.get(s.player_id) ?? 0) + s.goals)
      }
    })

    await onSave({
      played_at: date,
      match_time: matchTime.trim() || null,
      team_a_name: teamAName,
      team_b_name: teamBName,
      score_a: isUpcoming ? null : scoreA,
