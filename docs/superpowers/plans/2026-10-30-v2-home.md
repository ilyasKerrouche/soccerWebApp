# v2 Home con campo 3D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sostituire la home con: ultima partita su un campo 3D realistico e fermo (card vere, targhette, LED dati, sponsor a rotazione), riquadro voto MOTM, schede Riepilogo · Risultati · Classifica con "Il tuo riepilogo".

**Architecture:** Server component `app/page.tsx` (resta `revalidate = 60`) prepara i dati pubblici; i dati per-utente arrivano da una nuova server action chiamata dal client. Il campo è CSS 3D disegnato a dimensione doppia e rimpicciolito con `translateZ`. La logica pura (testo LED, stato del riquadro voto, conti alla rovescia, orari Europe/Rome) vive in moduli `lib/` testati con `node --test`.

**Tech Stack:** Next.js 14 app router, React 18, Tailwind, Supabase, `node --test` (Node 24, type stripping).

**Spec:** `docs/superpowers/specs/2026-10-30-v2-home-design.md`

## Global Constraints

- Nessuna nuova dipendenza. Campo in CSS 3D (niente Three.js/WebGL).
- Colori home: fondo `#0d1420`, superfici `#141d2b` / `#1a2536`, testo `#e8ecf2`, secondario `#8a96a8`, accento `#5b9cff`, oro MOTM `#f5c451`.
- Testi UI in italiano. Fuso orario `Europe/Rome` per date, orari, testo LED.
- `app/page.tsx` resta `revalidate = 60`: nessun dato per-utente nell'HTML del server (né "hai votato", né il riepilogo personale).
- MOTM (oro, ★, "MOTM" nel LED/titolo) solo a voto **chiuso** (`getMotmWinnersByMatch`).
- `prefers-reduced-motion: reduce` → niente entrata delle card, niente scorrimento LED, niente rotazione sponsor (primo sponsor fermo).
- Pubblicità solo con gli sponsor inventati dello spec.
- Mockup di riferimento (non versionati): `.superpowers/brainstorm/59685-1793365679/content/pubblicita.html` (campo, variante `rot`) e `home-layout1-v2.html` (pagina).

## Review Focus

1. **Nessuna partita giocata** — la home mostra "Nessuna partita registrata." e non crasha (niente campo, niente riquadro voto). → test in Task 1 (`buildLedText` con dati vuoti) + verifica manuale Task 4.
2. **Testo LED senza MOTM/marcatori/prossima partita** — si omettono le parti, nessun "·" doppio o finale. → test Task 1.
3. **Visitatore admin o account in attesa** — riquadro voto con "Vedi", mai "Accedi"; niente riepilogo. → test Task 1 (`voteCta`).
4. **Conto alla rovescia a zero mentre la pagina è aperta** — il riquadro voto sparisce, nessun numero negativo. → test Task 1 (`countdownParts` ≤ 0 → null).
5. **Ultima partita giocata a cavallo di mezzanotte UTC** — data e ora mostrate in ora italiana. → test Task 1 (`formatRome*`).
